# Fonts

Self-hosted Latin variable WOFF2 subsets from Google Fonts, including Spanish accents. All three families use the SIL Open Font License 1.1; the accompanying OFL files contain the copyright notices and license terms.

| Family | File | Upstream source | License |
| --- | --- | --- | --- |
| Geist | `geist-latin-variable.woff2` | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/geist) | `geist-OFL.txt` |
| IBM Plex Sans | `ibm-plex-sans-latin-variable.woff2` | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/ibmplexsans) | `ibm-plex-sans-OFL.txt` |
| Martian Mono | `martian-mono-latin-variable.woff2` | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/martianmono) | `martian-mono-OFL.txt` |

Downloaded through the Google Fonts CSS API with normal width and these weight ranges: Geist 100–900, IBM Plex Sans 100–700, Martian Mono 100–800. Only normal (not italic) styles are used. The site does not depend on third-party font servers at runtime.
